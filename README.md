# Mi Web Personal

Página personal creada con HTML, CSS y JavaScript para mostrar información sobre mí, mis intereses y mis enlaces principales.

## Descripción

Esta web funciona como portfolio personal y presenta:

- una introducción sobre mí
- información de formación y intereses
- enlaces a plataformas como Spotify y Letterboxd
- contacto con GitHub y correo

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Cómo ver el proyecto

1. Clona este repositorio.
2. Abre la carpeta del proyecto.
3. Ejecuta el archivo `index.html` en tu navegador.
